## 2. Документы

### 2.1. Заказ поставщику

Карточка:
- [ ] «Открыть заявку», «Открыть поставщика», «Открыть договор» открывают нужный объект; при пустой ссылке команда недоступна
- [ ] «Создать подтверждение» открывает новую карточку «Подтверждение услуги» с заполненной шапкой и табличной частью; новый документ не записан
- [ ] «Пересчитать суммы» выводит сообщение про этап 4, документ не записывается и не проводится
- [ ] В табличной части «Услуги» строка с количеством или суммой ≤ 0 подсвечена красным

Журнал:
- [ ] «Показать просроченные» оставляет только строки с просроченной датой ожидания и статусом «Отправлен» / «Частично подтверждён»
- [ ] «Сбросить отбор» возвращает полный список
- [ ] Просроченные строки подсвечены красным

### 2.2. Подтверждение услуги

Карточка:
- [ ] «Открыть заказ» открывает заказ поставщику
- [ ] «Выполнить сверку» выводит сообщение про этап 4, документ не меняется
- [ ] При результате сверки «Есть расхождения» поле подсвечено жёлтым
- [ ] В «Подтверждённые услуги» строка с количеством ≤ 0 подсвечена красным

Журнал:
- [ ] Строки с расхождениями подсвечены жёлтым; при «Совпадает» подсветки нет

### 2.3. Маршрутный лист

Карточка:
- [ ] «Открыть заявку», «Открыть туриста» открывают нужный объект
- [ ] «Пересчитать тайминги» выводит сообщение про этап 4

Журнал:
- [ ] Статус «В пути» — жёлтая подсветка; «Завершён» — серая

### 2.4. Событие маршрута

Карточка:
- [ ] «Открыть маршрутный лист» открывает маршрутный лист
- [ ] «Пересчитать локальное время» выводит сообщение про этап 4
- [ ] Буфер до следующего события меньше нуля — поле подсвечено красным

Журнал:
- [ ] Отрицательный буфер — красная подсветка; пустой и неотрицательный — без подсветки

### 2.5. Корректировка маршрута

Карточка:
- [ ] «Открыть маршрутный лист» открывает маршрутный лист
- [ ] «Применить корректировку» выводит сообщение про этап 4

Журнал:
- [ ] Несогласованные корректировки («Согласовано» = Ложь) подсвечены жёлтым

### 2.6. Заявка туриста на маршруте

Карточка:
- [ ] «Открыть маршрутный лист», «Открыть туриста» открывают нужный объект
- [ ] «Рассчитать срок SLA» выводит сообщение про этап 4
- [ ] Просроченный срок SLA при статусах «Новый», «В работе», «Ожидает поставщика» — красная подсветка; при «Исполнен» и «Отклонён» подсветки нет

Журнал:
- [ ] «Показать просроченные» оставляет строки с просроченным SLA и незавершённым статусом
- [ ] «Сбросить отбор» возвращает полный список
- [ ] Просроченные строки подсвечены красным, исполненные — нет

### 2.7. Инцидент

Карточка:
- [ ] «Открыть заявку», «Открыть поставщика» открывают нужный объект
- [ ] «Создать претензию» открывает новую карточку «Претензия поставщику» с заполненными инцидентом, поставщиком, договором и суммой
- [ ] «Классифицировать» выводит сообщение про этап 4
- [ ] При тяжести «Тяжёлый» поле подсвечено жёлтым

Журнал:
- [ ] Тяжёлый незакрытый инцидент — красная подсветка; «Урегулирован» — зелёная

### 2.8. Претензия поставщику

Карточка:
- [ ] «Открыть инцидент», «Открыть договор» открывают нужный объект
- [ ] «Создать акт» открывает новую карточку «Акт о компенсации» с переносом структуры компенсации
- [ ] «Рассчитать компенсацию» выводит сообщение про этап 4
- [ ] Сумма требования больше порога и не согласована руководителем — красная подсветка
- [ ] Пока константа «Порог согласования руководителем» равна 0, подсветка не появляется

Журнал:
- [ ] «Отклонена» — красная, «Оплачена» — зелёная, сумма выше порога без согласования — жёлтая

### 2.9. Акт о компенсации

Карточка:
- [ ] «Открыть претензию», «Открыть инцидент» открывают нужный объект
- [ ] «Пересчитать структуру» выводит сообщение про этап 4

Журнал:
- [ ] Строка, где компенсация туристу больше взыскания с поставщика, подсвечена жёлтым

## 3. Справочники

### 3.1. Карточки: общее

На каждой карточке справочника:

- [ ] Группа «Дополнительно» свёрнута при открытии и разворачивается по клику
- [ ] Обязательные реквизиты стоят в шапке и подсвечиваются при попытке записи пустыми
- [ ] У видимых полей есть содержательные подсказки (не пустые)

### 3.2. Карточки: что где лежит

| Справочник | Проверить |
|---|---|
| Туристы | в «Дополнительно»: Email, предпочтения питания, медицинские особенности, менеджер |
| Поставщики | в «Дополнительно»: КПП, юр. адрес, контактное лицо |
| ДоговорыСПоставщиками | в «Дополнительно»: условия late check-in, условия отмены, максимальная компенсация; **просроченная дата окончания подсвечена красным** |
| ОбъектыГостеприимства | в «Дополнительно»: координаты, рейтинг, email ресепшн |
| НоменклатураУслуг | в «Дополнительно»: базовая цена |
| ТипыЗапросовТуристов | в «Дополнительно»: шаблон ответа |
| ТипыИнцидентов | в «Дополнительно»: шаблон претензии, типовой процент компенсации |
| Сотрудники | в «Дополнительно»: пользователь 1С, телефон, email |
| ЗаявкиНаТур | «Дополнительно» нет — все реквизиты ключевые |
| СтраныМира, Валюты, ЕдиницыИзмерения, Пользователи, ТурыМаршруты | «Дополнительно» нет — проверяются только подсказки и обязательные |

### 3.3. Журналы справочников

- [ ] «Заявки на тур»: «Отменена» — серая подсветка, «Завершена» — зелёная
- [ ] «Поставщики»: правил подсветки нет
- [ ] «Пользователи»: поле «Имя пользователя ИБ» с подсказкой
