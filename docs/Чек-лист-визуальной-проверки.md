## 1. Навигация подсистем

Закрывает шаги 8.3.4 и 8.4.2 плана.

**Что платформа показывает в панели навигации, а что нет.** В панели навигации подраздела 1С выводит только команды открытия списков («Открыть …»). Стандартную команду «Создать …» платформа в панель навигации не помещает ни при каких настройках `CommandInterface` — проверено тремя вариантами записи (`Placement=Auto`, `Placement=Manual`, без `Placement`) и выгрузкой конфигурации из базы: записи сохраняются, но команда в панели не появляется. Создание в 1С живёт штатной кнопкой «Создать» в командной панели формы списка. Это зафиксированное отклонение от `design.md` D8, согласовано 2026-10-20.

Поэтому в подразделах проверяем «Открыть …» и отсутствие служебных команд, а создание — кнопкой «Создать» на открытом списке.

## 2. Документы

### 2.1. Заказ поставщику

Карточка:
- [ ] «Открыть заявку», «Открыть поставщика», «Открыть договор» открывают нужный объект; при пустой ссылке команда недоступна
- [ ] «Создать подтверждение» открывает новую карточку «Подтверждение услуги» с заполненной шапкой и табличной частью; новый документ не записан
- [ ] «Пересчитать суммы» выводит сообщение про этап 4, документ не записывается и не проводится

- [ ] «Показать просроченные» оставляет только строки с просроченной датой ожидания и статусом «Отправлен» / «Частично подтверждён»

## 3. Справочники

### 3.1. Карточки: общее

**Группы «Дополнительно» в справочниках нет** — это согласованное отклонение от D9: второстепенные реквизиты остаются в шапке. Свёрнутая группа есть только в трёх документах (`ЗаявкаТуристаНаМаршруте`, `Инцидент`, `ПодтверждениеУслуги`) — проверяй её там, а не в справочниках.

На каждой карточке справочника:

- [ ] Обязательные реквизиты стоят в шапке и подсвечиваются при попытке записи пустыми
- [ ] У видимых полей есть содержательные подсказки (не пустые)

### 3.2. Карточки: реквизиты на месте

| Справочник | На карточке должны быть |
|---|---|
| Туристы | ФИО, дата рождения, паспорт (серия, номер), телефон, гражданство, Email, предпочтения питания, медицинские особенности, менеджер |
| Поставщики | наименование, тип поставщика, ИНН, валюта расчётов, КПП, юр. адрес, контактное лицо |
| ДоговорыСПоставщиками | номер, дата окончания, условия late check-in, условия отмены, максимальная компенсация |
| ОбъектыГостеприимства | наименование, адрес, часовая зона, телефон ресепшн, координаты, рейтинг, email ресепшн |
| НоменклатураУслуг | наименование, вид услуги, единица, валюта, базовая цена |
| ТипыЗапросовТуристов | наименование, шаблон ответа |
| ТипыИнцидентов | наименование, шаблон претензии, типовой процент компенсации |
| Сотрудники | ФИО, должность, пользователь 1С, телефон, email |
| ЗаявкиНаТур, СтраныМира, Валюты, ЕдиницыИзмерения, Пользователи, ТурыМаршруты | все реквизиты ключевые, проверяются только подсказки и обязательные |

### 3.3. Журналы справочников

- [ ] «Заявки на тур»: «Отменена» — серая подсветка, «Завершена» — зелёная
- [ ] «Поставщики»: правил подсветки нет
- [ ] «Пользователи»: поле «Имя пользователя ИБ» с подсказкой
