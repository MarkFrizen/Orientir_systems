# Расчёты в формах и общие модули — план 5: интеграционная проверка и загрузка

> **For agentic workers:** REQUIRED SUB-SKILL: Use `/opsx-executing-plans form-calculations-and-shared-modules` to implement this plan task-by-task and sync progress back to OpenSpec. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Довести изменения до работающей базы: проверить конфигурацию и модули, загрузить её с обновлением БД, прогнать наполнение, проверку данных и xdd-смоук, затем привести проектную документацию в соответствие с реальностью.

**Architecture:** Проверки идут строго по возрастанию цены ошибки: сначала статический анализ исходников, потом компиляция, только потом загрузка в базу. Каждый шаг останавливает конвейер при провале — грузить непроверенную конфигурацию в файловую ИБ значит получить базу, которая не открывается. Откат — из DT-дампа плана 1 плюс `git revert`.

**Tech Stack:** 1С:Предприятие 8.3.27, файловая ИБ `db/КурсоваяРабота`, скиллы `cf-validate`, `meta-validate`, `db-load-xml`, `db-load-dt`, `db-run`, скрипты `epf/run-fill.ps1`, `epf/run-check.ps1`, `tests/vanessa/run-xdd-smoke.ps1`, MCP `1c-lsp-diagnostics`.

**Spec:**
- `openspec/changes/form-calculations-and-shared-modules/design.md` — раздел Migration Plan
- `openspec/changes/form-calculations-and-shared-modules/tasks.md` — задачи 7.1–7.7

## Global Constraints

- Платформа 8.3.27, режим совместимости `Version8_3_27`, управляемое приложение.
- ИБ файловая, `db/КурсоваяРабота`; клиент-сервер вне скоупа.
- Команды Конфигуратора запускаются с `-UserName "Администратор"`.
- JSON и PS1 сохраняются в UTF-8 с BOM; двойной BOM ломает XML.
- UUID роли `Администратор` не менять.
- Порог согласования в демо-данных — 50 000.
- Бэкап `db/backup/КурсоваяРабота-2026-10-20.dt` из плана 1 обязателен до загрузки конфигурации.

## Review Focus

- **Загрузка при ошибке компиляции.** `db-load-xml` с обновлением БД на сломанной конфигурации оставляет базу в непонятном состоянии — ожидается, что компиляция проверена до загрузки.
- **Повторный прогон наполнения.** `epf/run-fill.ps1` ищет существующие объекты по естественному ключу; ожидается, что второй прогон не создаёт дублей и не падает на новых правилах.
- **Незакрытые сеансы.** Файловая ИБ не даёт обновить конфигурацию при открытом клиенте — ожидается, что перед загрузкой процессы `1cv8`/`1cv8c` завершены.
- **Демо-данные с нулевыми суммами.** Часть документов создавалась непроведённой с нулевыми суммами; после включения правил их перезапись может отказать — ожидается, что `run-check.ps1` покажет это как нарушение, а не тихо пропустит.
- **xdd-смоук на 8.3.27.** Vanessa BDD 6.9.5 в проекте не работает, используется xdd-смоук на 82 шага — ожидается ровно 82/82, как на базовой линии.
