# Наполнение демо-данными — планы 1.1–2.4: подготовка и справочники

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Привести базу в состояние, из которого можно безопасно наполнять документы: бэкап, расширенный `SLAЧасов`, корректные сроки и SLA, целевые объёмы справочников и устойчивость прогона к ошибкам.

**Architecture:** Внешняя обработка `epf/ЗаполнениеНСИ` (логика в модуле формы) расширяется на месте: меняются значения в существующих процедурах, дополняются массивы данных, `ВыполнитьЗаполнение` получает блоки с изолированными `Попытка`. Метаданные правятся точечно — только квалификаторы `SLAЧасов`.

**Tech Stack:** 1С:Предприятие 8.3.27.1786, файловая ИБ `db/КурсоваяРабота`, исходники `src/КурсоваяРабота`, внешняя обработка `.epf`, PowerShell для запуска, BSL-модули.

**Spec:** `openspec/changes/seed-test-data/proposal.md`, `design.md`, `specs/demo-dataset/spec.md`

## Global Constraints

- Файловая ИБ `db\КурсоваяРабота`, платформа `C:\Program Files (x86)\1cv8\8.3.27.1786\bin`, пользователь `Администратор`, пароль пустой.
- Лицензия на одно место: перед любым запуском 1С закрыть процессы `1cv8`, `1cv8c`, `1cv8s`.
- Наполнение идемпотентно: существующие элементы не удаляются и не пересоздаются, повторный прогон не создаёт дублей.
- Целевые количества — итоговые, а не добавляемые к текущим.
- Даты набора фиксированные литералами, не от `ТекущаяДата()`.
- `build/`, `*.epf`, `*.log`, `db/**/*.cfl` в `.gitignore` — в коммиты не попадают.
- Строки в файловой ИБ — не длиннее 1024 символов.
- PS1/JSON для 1С — UTF-8 с BOM.

## Review Focus

- **Повторный прогон наполнения.** Пользователь запускает `run-fill.ps1` второй раз и ждёт те же количества — проверяется в задаче 1.6.
- **Ошибка в одном справочнике.** Прогон не должен обрываться, остальные блоки обязаны отработать — задача 1.7.
- **Существующие элементы с изменившимися значениями.** «Медицинская помощь» уже лежит с SLA 1 час и должна обновиться до 0,5 — задача 1.5.
- **Дробный SLA.** 0,5 часа не должно превратиться в 1 или 0 при записи — задача 1.2 и 1.5.
- **Договоры, подчинённые поставщику.** Новый договор без владельца создаст элемент, который не найдётся через `СсылкаПоНаименованию` — задача 1.6.
