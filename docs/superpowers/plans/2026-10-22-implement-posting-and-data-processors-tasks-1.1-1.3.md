# Проведение документов: примитивы и драйвер тестов — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Поднять автоматический набор тестов проведения и дать учётной механике два общих модуля-примитива: блокировки/движения/статусы/KPI и адресацию задач.

**Architecture:** Драйвер тестов — внешняя обработка по образцу `epf/ТестОбмена`, запускается через `1cv8.exe ENTERPRISE /Execute`, пишет отчёт с построчными проверками и вердиктом. Обработчики проведения живут в модулях объектов документов, повторяемые операции — в двух серверных общих модулях.

**Tech Stack:** 1С:Предприятие 8.3.27, файловая ИБ `db/КурсоваяРабота`, XML-выгрузка `src/КурсоваяРабота`, PowerShell 5.1, `epf-build`, xdd-смоук.

**Spec:** `openspec/changes/implement-posting-and-data-processors/specs/document-posting/spec.md`, `design.md` (D1, D4, D5, D9).

## Global Constraints

- Платформа 1С:Предприятие 8.3.27.1786, файловая ИБ; перед пакетным запуском закрыть окна 1С (лицензия на одно место).
- Исходники: `src/КурсоваяРабота`, создание метаданных — только через `meta-compile`, сборка EPF — через `epf-build`.
- Имена объектов, процедур и переменных — на русском.
- Порядок блокировок: сначала регистры накопления (`ВзаиморасчётыПоПретензиям`, `ШтрафыИКомпенсации`, `KPIОператоров`), затем регистры сведений (`СтатусыПодтверждений`, `ПараметрыУслуг`, `ГрафикПеремещений`, `ИсторияОбработокЗапросов`, `СтатусыИнцидентов`).
- Формат отчёта драйвера: строка `ПРОВЕРКА: <текст> — OK` или `ПРОВЕРКА: <текст> — FAIL (<детали>)`, последняя строка `ВЕРДИКТ: PASS` или `ВЕРДИКТ: FAIL`. Коды выхода раннера: 0 — PASS, 1 — FAIL, 2 — вердикт не найден.

## Review Focus

- Повторное проведение не дублирует движения регистров.
- Отмена проведения удаляет только записи своего регистратора.
- Разный порядок блокировок приводит к взаимной блокировке при встречном проведении.
- Ошибка в середине проведения оставляет частичные движения.
- Тест зелёный, а данные испорчены: драйвер меняет демо-набор и не убирает за собой.
