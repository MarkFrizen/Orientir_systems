# Обмен данными через CSV — форма и автотесты — План реализации

> **For agentic workers:** REQUIRED SUB-SKILL: используйте `/opsx-executing-plans add-csv-data-exchange` для реализации плана по задачам. Шаги отмечены чекбоксами (`- [ ]`).

**Goal:** Дать пользователю рабочую форму обмена в разделе «Администратор ИС» и закрыть механизм набором автотестов, которые не портят демо-набор.

**Architecture:** Форма — тонкая: путь к файлу, период, четыре команды, таблица результатов и поле вердикта. Вся логика уже в модуле объекта обработки, поэтому модуль формы только вызывает методы и раскладывает результат по реквизитам. Автотесты — два уровня: статические фикстуры в `tests/exchange/fixtures/` и PowerShell-скрипт, который гоняет сценарии драйвера, сверяет вердикты и убирает за собой.

**Tech Stack:** 1С:Предприятие 8.3.27.1786, управляемые формы, PowerShell, xddTestRunner, Python.

**Spec:** `openspec/changes/add-csv-data-exchange/specs/data-exchange/spec.md` (доступ из раздела администратора, частичная загрузка, вердикты), `openspec/changes/add-csv-data-exchange/design.md` (решения 9, 10, 11, 12, 13)

## Global Constraints

- Платформа `8.3.27.1786`, файловая ИБ `db/КурсоваяРабота`, тонкий клиент.
- `ТекущаяДатаСеанса()` недоступна на тонком клиенте — в клиентских процедурах не использовать, сборку отборов выносить на сервер.
- Формат обмена: UTF-8 с BOM, `;`, десятичная запятая, даты `ГГГГ-ММ-ДД`, булево `Истина`/`Ложь`.
- Тестовые объекты: наименование `ТЕСТ-`, код `999…`, номер документа `ТЕСТ-…`.
- Команды к базе — `-UserName "Администратор"`.
- Лицензия на одно место: перед прогоном закрыть все сеансы 1С; сироты `1cv8*` с `*TestClient*` убивать после прогона.
- PS1 и JSON — UTF-8 с BOM; XML — ровно один BOM.
- `ОбменДанными.Загрузка` не выставляется нигде.
- Коммиты — английские conventional-сообщения.

## Review Focus

- **Файл открыт в Excel во время загрузки** — запись в тот же файл упадёт. Ожидаемое поведение: пользователь видит текст «закройте файл», а не стек платформы, и форма остаётся рабочей.
- **Пустой путь к файлу** — нажатие кнопки без выбранного файла. Ожидаемое поведение: сообщение «Выберите файл», обработка не начинается, вердикт не меняется.
- **Период с началом позже окончания** — выгрузка заказов даст пустой файл молча. Ожидаемое поведение: предупреждение о перевёрнутом периоде до запуска выгрузки.
- **Таблица результатов на 300 ошибок** — форма не должна подвисать при выводе. Ожидаемое поведение: таблица заполняется на сервере и приходит на клиент одним значением.
- **Прогон тестов на непустой базе после ручных экспериментов** — очистка по префиксу не должна задеть демо-данные. Ожидаемое поведение: удаляются только объекты с `ТЕСТ-` или кодом `999…`, количество демо-объектов возвращается к 15 и 4.
