# Расчёты в формах и общие модули — план 4: пересчёты и команды в карточках документов

> **For agentic workers:** REQUIRED SUB-SKILL: Use `/opsx-executing-plans form-calculations-and-shared-modules` to implement this plan task-by-task and sync progress back to OpenSpec. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Заменить девять команд-заглушек рабочими обработчиками и заставить карточки документов считать сами: суммы строк, итог документа, результат сверки, срок SLA, локальное время, буферы, компенсацию и структуру акта.

**Architecture:** Клиентские обработчики только ловят событие и зовут серверную процедуру — арифметика и запросы живут в `&НаСервере`, потому что общие модули серверные, а `ТекущаяДатаСеанса()` на тонком клиенте недоступна. Пересчёт по `ПриИзменении` меняет объект формы в памяти и ничего не пишет; пишут только две команды, которым по смыслу нужно менять чужие документы (`ПересчитатьТайминги`, `ПрименитьКорректировку`), и обе спрашивают подтверждение.

**Tech Stack:** 1С:Предприятие 8.3.27, управляемое приложение, XML-выгрузка `src/КурсоваяРабота`, файловая ИБ `db/КурсоваяРабота`, скиллы `form-edit`, `form-validate`, `db-load-xml`, `db-run`, MCP `1c-lsp-diagnostics`.

**Spec:**
- `openspec/changes/form-calculations-and-shared-modules/design.md` — решения 2, 5, 6, 7
- `openspec/changes/form-calculations-and-shared-modules/specs/object-forms/spec.md`
- `openspec/changes/form-calculations-and-shared-modules/tasks.md` — задачи 6.1–6.11

## Global Constraints

- Платформа 8.3.27, режим совместимости `Version8_3_27`, управляемое приложение, вариант скрипта — русский.
- ИБ файловая, `db/КурсоваяРабота`; клиент-сервер вне скоупа.
- Метаданные и формы правятся только скиллами проекта; ручное редактирование XML запрещено.
- `ТекущаяДатаСеанса()` недоступна на тонком клиенте — даты только в `&НаСервере`.
- Строки модулей короче 1024 символов.
- Имена реквизитов, элементов и процедур — русские; отступы — табы; комментарии — по-русски.
- Денежные величины округляются только через `РасчётКомпенсаций.ОкруглитьСумму`.
- Пересчёт по `ПриИзменении` не пишет документ; запись выполняет только пользователь или команда с подтверждением.

## Review Focus

- **Изменение строки программно.** При заполнении ТЧ кодом `Элементы.Услуги.ТекущиеДанные` равно `Неопределено` — ожидается, что обработчик не падает, а просто выходит.
- **Нумерация строк.** `НомерСтроки` начинается с 1, индекс коллекции — с 0; путаница даёт пересчёт соседней строки — ожидается, что пересчитывается именно изменённая строка.
- **Пустая базовая цена.** У услуги может быть `БазоваяЦена` = 0 — ожидается подстановка нуля без падения и без затирания уже введённой цены.
- **Проведённые события маршрута.** Запись из формы меняет документ, у которого есть движения — ожидается предупреждение о необходимости перепроведения, а не молчаливое расхождение с регистром.
- **Источник базовой стоимости компенсации.** Прямой ссылки «инцидент → заказ поставщику» в конфигурации нет — ожидается явно задокументированное правило поиска, а не пустая сумма.
