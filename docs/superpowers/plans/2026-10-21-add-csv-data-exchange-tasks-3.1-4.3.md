# Обмен данными через CSV — механика CSV и драйвер — План реализации

> **For agentic workers:** REQUIRED SUB-SKILL: используйте `/opsx-executing-plans add-csv-data-exchange` для реализации плана по задачам. Шаги отмечены чекбоксами (`- [ ]`).

**Goal:** Реализовать механику CSV в общем модуле `ОбменCSV`, поднять исполняемый драйвер автотестов и отдать первую рабочую операцию — выгрузку номенклатуры услуг.

**Architecture:** Драйвер `epf/ТестОбмена` создаётся **первым**: обработку из конфигурации через `/Execute` не запустить, поэтому без внешнего EPF ни одну строчку 1С-кода не выполнить. Драйвер сразу содержит агрегатный сценарий `selftest`, который прогоняет три группы проверок (разбор, файл, типы) и печатает построчный результат — каждая следующая задача делает свою строку зелёной. Доменные методы живут в модуле объекта обработки `ОбменСФайлами`.

**Tech Stack:** 1С:Предприятие 8.3.27.1786, внешние обработки EPF, PowerShell, bsl-language-server.

**Spec:** `openspec/changes/add-csv-data-exchange/specs/data-exchange/spec.md` (требования про формат файла и выгрузку номенклатуры), `openspec/changes/add-csv-data-exchange/design.md` (решения 2, 3, 11)

## Global Constraints

- Платформа `8.3.27.1786`, файловая ИБ `db/КурсоваяРабота`, тонкий клиент.
- Модули `ОбменCSV` и `ОбменСФайлами` — серверные: `Сервер = Истина`, `ВызовСервера = Ложь`, `Клиент = Ложь`, `ВнешнееСоединение = Истина`, `Привилегированный = Ложь`.
- Формат обмена: UTF-8 с BOM, разделитель `;`, десятичная запятая, даты `ГГГГ-ММ-ДД`, булево `Истина`/`Ложь`.
- `ТекущаяДатаСеанса()` только в серверном контексте.
- Исходники и файлы для 1С — UTF-8; JSON/PS1 — UTF-8 с BOM; ровно один BOM.
- Команды к базе — `-UserName "Администратор"`, пароль пустой.
- Лицензия на одно место: перед прогоном закрыть все сеансы 1С.
- `ОбменДанными.Загрузка` не выставляется нигде.
- Коммиты — английские conventional-сообщения.

## Review Focus

- **Поле содержит и разделитель, и кавычку, и перевод строки одновременно** — наивный `СтрРазделить` развалит строку на лишние куски. Ожидаемое поведение: после `СобратьСтроку` → `РазобратьСтроку` массив совпадает с исходным, сколько бы мусора в поле ни было.
- **BOM в начале файла** — если не срезать `\uFEFF`, первая колонка заголовка станет `\uFEFFКод`, и поиск колонки промахнётся. Ожидаемое поведение: заголовок читается как `Код`.
- **Пустая строка файла** — Excel любит дописывать пустую строку в конец. Ожидаемое поведение: пустые строки не считаются данными и не порождают ошибок.
- **Файл открыт в Excel** — запись падает с ошибкой доступа. Ожидаемое поведение: понятное сообщение «закройте файл», а не стек платформы.
- **Кириллица в пути к файлу** — путь передаётся через `ПараметрЗапуска`, где пробелы и кириллица ломают наивную склейку командной строки. Ожидаемое поведение: драйвер находит файл по пути с пробелами.
