# Наполнение демо-данными — план 2: документы (3.1–3.6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать двадцать документов девяти видов, связанных в три сквозных сценария, с заполненными табличными частями и идемпотентным повторным прогоном.

**Architecture:** В модуль формы `ЗаполнениеНСИ` добавляются две служебные функции — поиск документа по естественному ключу и создание при отсутствии. Каждая процедура `ЗаполнитьДокументы*` описывает свой вид документа массивом структур и вызывает `ОбеспечитьДокумент`. Новые блоки подключаются к диспетчеру `ВыполнитьБлок` из плана 1.

**Tech Stack:** 1С:Предприятие 8.3.27.1786, BSL, внешняя обработка `.epf`, PowerShell-запуск.

**Spec:** `openspec/changes/seed-test-data/specs/demo-dataset/spec.md`, `design.md` (решения 3 и 5)

## Global Constraints

- Наполнение идемпотентно: повторный прогон не создаёт дублей и не пересоздаёт существующие документы.
- Даты фиксированные, сентябрь–октябрь 2026; дата инцидента не позже 18.10.2026.
- Документы создаются **непроведёнными**: `Записать()`, без `Провести()` и без `РежимЗаписиДокумента.Проведение`.
- Все ссылки — только на существующие элементы; `СсылкаПоНаименованию` бросает исключение при отсутствии, это ожидаемо.
- Строки — не длиннее 1024 символов (файловая ИБ).
- `build/` и `*.epf` в `.gitignore` — коммитятся только исходники.
- Перед запуском 1С закрыть процессы `1cv8`, `1cv8c`, `1cv8s`.

## Review Focus

- **Повторный прогон после частичного сбоя.** Документ, созданный в прошлом прогоне, должен находиться по ключу, а не дублироваться — задача 2.1.
- **Расхождение в подтверждении.** `РезультатСверки = ЕстьРасхождения` и фактическая цена 50 при заказанной 45 — задача 2.2.
- **Заказ без подтверждения.** Четвёртый заказ обязан остаться без `ПодтверждениеУслуги` — задача 2.2.
- **Корректировка ссылается на событие.** `КорректировкаМаршрута.СобытиеМаршрута` — ссылка на реально созданное событие, а не на новое — задача 2.3.
- **Пустые табличные части.** `АктОКомпенсации.СтруктураКомпенсации` и `ЗаявкаТуристаНаМаршруте.ИсторияОбработки` без строк — задача 2.4 и 2.5.
