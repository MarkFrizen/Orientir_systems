# Реестр скриншотов для отчёта по тестированию

Папка для кадров, подтверждающих прогон типовых сценариев (`docs/Сценарии-работы-пользователей.md`). Отчёт, который на них ссылается: `docs/Отчёт-тестирования-по-сценариям.md`.

## Как снимать

1. Масштаб экрана — 100 %, разрешение не меньше 1280x720, окно 1С развернуть.
2. Снимок: `Win + Shift + S` (фрагмент окна) или `Alt + PrtScr` (активное окно).
3. Сохранять в эту папку, имя файла — **строго из таблицы** (латиница, номер в начале).
4. В кадр не должно попадать: рабочий стол, другие окна, личные данные, панель задач.
5. Если сообщение об ошибке исчезает — снимать сразу, не закрывая окно. Для повторяемых отказов можно вызвать ошибку ещё раз.
6. После съёмки поставить в таблице отметку «снят».

## Подготовка базы перед съёмкой

| # | Что проверить | Как | Если не так |
|---|---|---|---|
| 1 | Демо-документы проведены | открыть `Акт о компенсации` и `Маршрутный лист`, посмотреть, есть ли движения/записи в регистрах | провести документы (акт, претензию, подтверждения, маршрутные листы) |
| 2 | Есть учётная запись гида | раздел «Администратор ИС» → «Пользователи» / список пользователей ИБ | создать пользователя с ролью `Профиль_Гид` |
| 3 | База соответствует демо-набору | `epf/run-check.ps1` → вердикт `PASS` | пересоздать базу и запустить `epf/run-fill.ps1` |
| 4 | Свободны сеансы 1С | в диспетчере задач нет `1cv8*` перед запуском тестов | закрыть клиент |
