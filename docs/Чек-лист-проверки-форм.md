# Чек-лист ручной проверки форм

Отмечай `[x]` — прошло, `[!]` — не так, с коротким описанием.

**Подготовка:** 1С в режиме «Предприятие», пользователь `Администратор`, пароль пустой. Если в журнале нет подходящей строки — создай документ вручную (дата в прошлом + нужный статус), запиши без проведения, после проверки пометь на удаление.

---

## 1. Карточки: группы, подсказки, обязательные

- [ ] **1.1 НСИ.** «Администратор ИС» → «Справочники НСИ» → `Валюты` → открыть элемент. Ожидание: `Наименование` и `Код` в шапке, группа «Дополнительно» свёрнута, подсказка на `Код` есть.
- [ ] **1.2 Туристы.** В шапке `ФИО`, `Дата рождения`, `Телефон`, `Гражданство`; в «Дополнительно» — `Email`, `Предпочтения питания`, `Медицинские особенности`, `Менеджер`.
- [ ] **1.3 Договоры с поставщиками.** В «Дополнительно» `Максимальная компенсация`, `Условия late check in`, `Условия отмены`.
- [ ] **1.4 Инцидент.** Группа «Тексты» свёрнута, внутри `Описание` и `Текст ИИ`; `Автор регистрации` — в «Дополнительно».
- [ ] **1.5 Заказ поставщику.** `Комментарий` внизу страницы «Основное», не в «Дополнительно».
- [ ] **1.6 Обязательные.** В `Заказ поставщику` очистить `Поставщик` → «Записать». Ожидание: сообщение о незаполненном, поле отмечено.

## 2. Подсветка журналов

- [ ] **2.1 Заказы поставщикам.** Просроченная `Дата ожидания подтверждения` + статус `Отправлен`/`Частично подтверждён` → красная. `Подтверждён`/`Отклонён` — без подсветки.
- [ ] **2.2 Запросы туристов.** Просроченный `Срок SLA` + `Новый`/`В работе`/`Ожидает поставщика` → красная. `Исполнен`/`Отклонён` — без подсветки.
- [ ] **2.3 Подтверждения.** `Результат сверки` = `Есть расхождения` → жёлтая.
- [ ] **2.4 Инциденты.** `Тяжёлый` и не `Закрыт` → красная; `Урегулирован` → зелёная.
- [ ] **2.5 Претензии.** `Отклонена` → красная, `Оплачена` → зелёная. Сумма выше порога без согласования → жёлтая (порог задать, см. 3.1).
- [ ] **2.6 Заявки на тур.** Журнал: `Отменена` → серая, `Завершена` → зелёная.
- [ ] **2.7 Маршрутные листы.** `В пути` → жёлтая, `Завершён` → серая.
- [ ] **2.8 События маршрута.** `Буфер до следующего` < 0 → красная.
- [ ] **2.9 Корректировки.** `Согласовано` = Ложь → жёлтая.
- [ ] **2.10 Акты компенсации.** Компенсация туристу больше взыскания с поставщика → жёлтая.

## 3. Подсветка карточек

- [ ] **3.1 Порог согласования.** «Все функции» → Константы → `Порог согласования руководителем` = 100 000. Открыть претензию на 150 000 без согласования → `Сумма требования` красная. На 50 000 — без подсветки.
- [ ] **3.2 Событие маршрута.** `Буфер` = −15 → поле красное; 30 → обычное.
- [ ] **3.3 Заказ поставщику.** В ТЧ `Услуги` количество 0 → ячейка красная.
- [ ] **3.4 Подтверждение услуги.** `Результат сверки` = `Есть расхождения` → жёлтый; количество 0 в ТЧ → красное.
- [ ] **3.5 Договор.** `Дата окончания` в прошлом → красная.
- [ ] **3.6 Заявка туриста.** Просроченный `Срок SLA` + незавершённый статус → красное поле; `Исполнен` — без подсветки.
- [ ] **3.7 Инцидент.** `Уровень тяжести` = `Тяжёлый` → жёлтый.

## 4. Команды

- [ ] **4.1 Навигация.** `Заказ поставщику` → «Открыть заявку» открывает заявку. Очистить `Заявка на тур` → команда недоступна.
- [ ] **4.2 Навигация, выборочно.** `Подтверждение услуги` → «Открыть заказ»; `Маршрутный лист` → «Открыть туриста»; `Инцидент` → «Открыть поставщика»; `Претензия` → «Открыть договор»; `Акт` → «Открыть претензию».
- [ ] **4.3 Создание на основании.** `Заказ поставщику` → «Создать подтверждение». Ожидание: открылся новый документ, заполнены заказ, поставщик, ТЧ. Закрыть без записи → нового документа нет.
- [ ] **4.4** `Инцидент` → «Создать претензию». Заполнены инцидент, поставщик, действующий договор, сумма.
- [ ] **4.5** `Претензия` → «Создать акт». Заполнены претензия, инцидент, сумма взыскания, дата акта.
- [ ] **4.6 Отбор.** Журнал заказов → «Показать просроченные» → только просроченные; «Сбросить отбор» → все строки.
- [ ] **4.7 Отбор.** Журнал запросов туристов → то же самое.
- [ ] **4.8 Заготовки.** `Заказ поставщику` → «Пересчитать суммы» → сообщение «…будет реализовано на этапе 4», документ не записан и не проведён.
- [ ] **4.9 Права (опционально).** Пользователь без прав на `Претензия поставщику`: в инциденте команда «Создать претензию» недоступна.

## 5. Регресс и ограничения

- [ ] **5.1** По одной форме каждого типа открываются без ошибок: справочник, документ, журнал.
- [ ] **5.2** Подсветка не мешает: запись, проведение и закрытие формы работают.
- [ ] **5.3** Известное ограничение: отрицательные остатки по `График перемещений` не подсвечиваются — движений нет до этапа 4. Это ожидаемо.
