## 2. Причина

Движения писались в обход коллекции `Движения` — через
`РегистрыСведений.X.СоздатьНаборЗаписей()` + `Записать(Истина)`.
При `ЗаписьДвиженийПриПроведении = Записывать выбранные` платформа в конце
проведения записывает коллекцию `Движения` и затирает записи, сделанные мимо
неё. Коллекция инициализирована только при записи из открытой формы — поэтому
из журнала, COM и тестового драйвера записи выживали, а из формы нет.
