# Spec Delta

## ADDED Requirements

### Requirement: Порог согласования редактируется из раздела администратора

Константа `ПорогСогласованияРуководителем` SHALL быть доступна из раздела «Администратор ИС» и SHALL редактироваться пользователем, у которого есть право изменения этой константы. Изменённое значение SHALL применяться правилом проверки претензии.

#### Scenario: Администратор открывает константу

- **WHEN** пользователь с правом изменения открывает раздел «Администратор ИС»
- **THEN** в панели навигации доступна команда «Порог согласования руководителем», открывающая форму константы со значением 50 000

#### Scenario: Изменение порога

- **WHEN** администратор меняет значение с 50 000 на 100 000 и записывает
- **THEN** претензия на 60 000 без признака согласования записывается без отказа, а претензия на 120 000 отклоняется требованием согласования

#### Scenario: Пользователь без права изменения

- **WHEN** пользователь без права изменения константы открывает её форму
- **THEN** форма открывается только для просмотра, запись недоступна

### Requirement: Технические объекты не образуют отдельного раздела

Подсистема «Сервис» SHALL отсутствовать. Планы видов характеристик, задача исполнителя и регистр адресации задач SHALL входить в раздел «Администратор ИС» и SHALL NOT отображаться в его панели навигации.

#### Scenario: Раздел отсутствует в главном меню

- **WHEN** пользователь открывает главное меню
- **THEN** раздела «Сервис» нет

#### Scenario: Технические объекты скрыты в навигации

- **WHEN** пользователь открывает раздел «Администратор ИС»
- **THEN** в панели навигации нет команд «Дополнительные реквизиты туриста», «Дополнительные реквизиты услуг», «Задачи исполнителя» и «Адресация задач»

#### Scenario: Настройки интеграций не задеты

- **WHEN** пользователь открывает подраздел «Настройки интеграций»
- **THEN** регистр `НастройкиИнтеграций` по-прежнему доступен для просмотра и изменения
